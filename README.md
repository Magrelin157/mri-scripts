# mri-scripts

Scripts do servidor **Atitude RP** (FiveM, Qbox / MRI).

| Script | Descrição |
|---|---|
| [qbx_vehicleshop](qbx_vehicleshop/) | Concessionária com painel de catálogo (prévia do veículo, cores, test drive com cronômetro, financiamento), sem carros expostos e sem veículos vanilla na loja. |
| [lunar_fishing](lunar_fishing/) | Sistema de pesca (zonas, níveis, NPC vendedor, aluguel de barco) com minigame no estilo Stardew Valley e painel próprio de compra e venda no lugar dos menus do ox_lib. |

Cada pasta é um resource independente: copie a pasta para o `resources` do servidor e dê `ensure` no nome dela.
Cada script tem a própria licença dentro da pasta.
